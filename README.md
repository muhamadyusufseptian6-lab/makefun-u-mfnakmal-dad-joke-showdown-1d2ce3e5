Entry for the make.fun bounty **Dad Joke Showdown** (`u-mfnakmal-dad-joke-showdown-1d2ce3e5`).

`main.ts` (Node 22, stdlib only, deterministic) writes a single dad joke — at
most 200 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. One joke is the
whole entry: a clean pun, fresh but firmly inside the dad joke tradition,
tight, with the punchline at the end, written to be read out loud at the
dinner table.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dad-joke-out node main.ts
cat /tmp/dad-joke-out/entry.txt
```
